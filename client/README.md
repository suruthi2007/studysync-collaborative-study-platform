# 📚 StudySync — Frontend Client

Frontend client for the StudySync real-time collaborative study platform, built with React 19, Vite, Tailwind CSS / Vanilla CSS, Socket.io client, and WebRTC.

## 🚀 Running Locally

```bash
# From the client directory
npm install
npm run dev
```

App will run at `http://localhost:5173`. Make sure the backend server is running at `http://localhost:5000` (or configured via `.env`).
